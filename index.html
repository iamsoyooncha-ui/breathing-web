Manifesto

  1. This website is not a page. It is an organism.
  2. It feeds on data/stories.
  3. It grows as much as it eats.
  4. When it cannot feed, it stops.
  5. The artist/maker writes only the rules. The artist/maker does not write the form.
  6. The process of sharing stories is the work.

For a long time, the web has been understood as a container for information.

This work overturns it. Here, the website just lives.

The site takes interaction (uploading recipes, stories) as nourishment (growing web).

The artist/maker does not design its shape.
The artist/maker defines only the rules of growth and decay.

A website is an organism.

Visitors are not viewers but feeders, their attention and intervention (interaction with the web) become the conditions of the organism's growth.
