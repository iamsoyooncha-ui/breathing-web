# The Fermentary · Growing organism

A website where people plant photos and recipes of fermented foods on cities across a 3D globe, comment on them, and link them together so the archive grows.
Like a living organism, the site grows on interaction (food) and goes dormant when left alone.

- `index.html` — the whole site (d3 globe + canvas hyphae animation). Paste your Supabase URL and anon key at the top of the script to make it shared.
- `supabase/setup.sql` — Supabase database, storage and permission setup (run once)
- `supabase/add-cities.sql` — only if you ran an older `setup.sql` before cities were added
